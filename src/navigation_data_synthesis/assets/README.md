# 导航场景资产

`Third_Floor.usd` 的 `/PhysicsScene` 使用 PhysX **TGS** 求解器，物理步频为 **120 Hz**。
在 `EVT-EXP.usd` 的多关节滚子轮机器人零指令测试中，TGS 消除了原 PGS 设置下的持续毫米级位置振动。
场景保留浮动底盘、关节驱动和轮地碰撞。修改场景文件后，停止仿真并重新打开场景以加载设置。

向场景添加 `EVT-EXP.usd` 时，引用它的默认模型根节点 `/EVT_3`。
机器人文件另含独立预览用的 `/PhysicsScene` 和 `/GroundPlane`；引用默认模型根节点即可使用三楼场景自身的物理场景与地面。
